🚲 Cycle Champs – Privacy Policy

Last updated: 28 October 2026

In short: Cycle Champs is a game for children. It has no ads, no accounts, no in-app purchases, no analytics or tracking, and it does not collect any personal information. Everything a child does in the game stays on their own device.

Information we collect

We do not collect, store, sell or share any personal information. We have no servers that receive information about players.

Information kept on the device only

To save progress, the game stores the following only on the phone or tablet, and never sends it anywhere:

  • Stars, best times, stickers found, garage choices and tracks the child draws.
  • An optional first name typed for the Junior Cycling Licence card.
  • An optional bike colour picked from a photo. The photo itself is read once on the device to find a colour and is not stored or uploaded.

Deleting the app removes all of this.

Internet use

The app connects to the internet only to check our own website for a newer version of the game and download it. This request contains no personal information and no identifiers. The website is hosted on GitHub Pages, and like any website host, GitHub may briefly keep the device's IP address in its security logs; we never receive or use it. Voice tips use the device's built-in text-to-speech, which works offline.

Sharing

Children can save or share a picture of their licence, a track QR code or a trick video using the device's own share menu. This is protected by a parental gate (a question for a grown-up), and nothing is shared unless the grown-up chooses where to send it.

Children's privacy (COPPA and India's DPDP Act)

Because we collect no personal information, there is nothing to review or delete on our side. Parents can delete all game data at any time by uninstalling the app.

Changes

If this policy changes, we will update this page and the date above.
